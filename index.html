Level screen

Every skill reaches Level 99 at 100,000 XP. Earning rates differ by activity frequency so the intended time-to-mastery remains balanced. Each bar shows progress within the current level and the precise XP needed for the next level. Mastery recognises extra effort without accelerating Account Level.

Recovery centre

Current local save

Your progress is stored locally in this browser installation. Export before changing devices, browsers or website addresses.

Export account

Downloads a JSON copy of your complete account, daily logs, targets, XP and profile.

Import account

Imports a Consistency Quest JSON backup. The current save is copied to a safety backup before replacement.

Recovery scan

This can recover from cq3, the rolling backup or the pre-import backup in this browser installation. It cannot read storage belonging to a different website address or browser installation.

Safety backup

The app keeps a rolling browser-local backup and a separate pre-import backup where available.
